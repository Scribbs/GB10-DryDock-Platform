# Acknowledgements

This deployment package builds upon and integrates the following open-source and NVIDIA projects. We gratefully acknowledge the original authors and maintainers.

## NVIDIA AI Blueprint: Vulnerability Analysis for Container Security

- **Repository**: https://github.com/NVIDIA-AI-Blueprints/vulnerability-analysis
- **License**: Apache License 2.0
- **Description**: Multi-agent workflow (NeMo Agent Toolkit + NIM) that performs contextual analysis of container vulnerabilities and produces VEX classifications with cited reports.
- **Usage in this project**: The core analysis engine. We deploy the official Docker Compose stack and feed it `PipelineInput` generated by our processor.

Full license text is included in `licenses/NVIDIA-vulnerability-analysis-Apache-2.0.txt`.

## Syft (Anchore)

- **Repository**: https://github.com/anchore/syft
- **License**: Apache License 2.0
- **Description**: CLI tool and library for generating SBOMs from container images and filesystems (CycloneDX, SPDX, etc.).
- **Usage in this project**: SBOM generation step in the processor container.

## Trivy (Aqua Security)

- **Repository**: https://github.com/aquasecurity/trivy
- **License**: Apache License 2.0
- **Description**: Comprehensive vulnerability scanner for containers, filesystems, and SBOMs.
- **Usage in this project**: CVE extraction that populates the vulnerability list passed to the NVIDIA blueprint.

## Optional / Recommended Components

- **Grype** (Anchore) – Alternative or complementary vulnerability scanner.
- **NVIDIA NIM / NeMo Agent Toolkit** – Inference and agent orchestration runtime.
- **Tavily** – Web search / research tool used by the blueprint’s CVE researcher agent.
- **Docker / Docker Compose** – Container runtime.
- **Streamlit** (or FastAPI + frontend of choice) – Web UI framework.

## Dell / NVIDIA GB10 Hardware

Deployment guidance for 2-node clustering references public NVIDIA DGX Spark playbooks and community guides for ConnectX-7 QSFP DAC interconnects. No proprietary Dell code is included.
